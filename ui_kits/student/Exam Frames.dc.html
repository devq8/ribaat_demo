Exam taking — full flow Start · in-progress (three question types, timed + untimed headers) · submit confirmation · submitted. Light and dark, desktop / tablet / mobile.
Every frame is the same live component (ExamTaking.dc.html) — the navigator, timer, flagging and answer state are interactive in place. Tweaks: question-navigator style (labelled list · chips · number grid), navigator row labels, key placement (outside the box · inside · hidden), True/False control style (compact buttons · segmented · large tiles), plus screen, theme, breakpoint, timing, flagging and results policy.
5a Desktop · Light — in progress, MCQ, timed header
1360px. Navigator rail on the inline-end (left) side so the question keeps the RTL reading start; sticky under the header. Default navigator is a labelled question list — ✓ answered, hollow circle unanswered, flag for review — with the key as a plain caption below the box, not a row of button-like swatches inside it.
5b Desktop · Light — True/False (compact), untimed header variant
Untimed exams state «بدون وقت محدد» in the timer slot rather than leaving a gap. True/False is a pair of small buttons — much shorter than an MCQ row, so the type reads instantly. Segmented and large-tile alternatives are in Tweaks.
5c Desktop · Light — short answer (paragraph)
Textarea sized to the expected answer; the hint states the expected length.
5d Desktop · Light — short answer (one line), flagged
Unanswered + flagged for review: flag marker in the navigator row, brown-tinted flag control in the question header.
5e Desktop · Dark — timer in its low-time state
Under five minutes the timer moves to the muted amber pair (#3A2F1C / #D3A85C in dark) — legible, no flashing, no red siren. Held static at 04:38 so the state stays inspectable; the live countdown and its auto-submit run in 5a.

5l Submit confirmation · Desktop Light

5n Submitted · Desktop Light — results later (default)
No score. Receipt rows + a plain statement that the teacher reviews and the result appears on the course page. Open question — see 5o for the immediate-score variant.
5o Submitted · Dark — immediate score variant
Only viable if the exam is all objective, or if a provisional score is acceptable while essay answers are still pending.
5p Time expired · Desktop Light — auto-submitted
When the countdown reaches 00:00 the exam closes itself and lands here: amber clock instead of the green check, «انتهى وقت الاختبار وسُلِّم تلقائياً», and the receipt names the unanswered count outright. Saved answers are kept — nothing is discarded.
